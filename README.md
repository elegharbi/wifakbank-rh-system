# Wifak Bank — Système de Gestion RH

Portail RH interne de Wifak Bank : espace collaborateur, espace RH et espace
administrateur, avec assistant conversationnel intégré.

**Stack** — Spring Boot 3.2.5 (Java 17) · Angular 20 · PostgreSQL 17

## Aperçu

Quatre rôles, chacun avec son espace :

| Rôle | Accès |
|---|---|
| `EMPLOYEE` | Tableau de bord, congés, points & classement, formations, événements, profil |
| `HR` | Gestion des congés, recrutement, formations, annonces, départements |
| `ADMIN` | Utilisateurs, départements, paramètres, statistiques |
| `CANDIDATE` | Candidature, suivi des postulations |

Fonctionnalités transverses : thème clair/sombre persistant, bilingue FR/AR,
assistant RH avec historique de conversations, import de photo de profil.

## Prérequis

| Outil | Version | Vérifier |
|---|---|---|
| JDK | 17+ | `java -version` |
| Node.js | 20+ | `node -v` |
| PostgreSQL | **10 minimum** | `psql --version` |
| Maven | 3.9+ | `mvn -v` |

> **PostgreSQL 10 est un minimum strict.** Toutes les entités utilisent
> `GenerationType.IDENTITY`, qu'Hibernate 6.4 traduit en
> `GENERATED BY DEFAULT AS IDENTITY` — une syntaxe absente avant la version 10.

## Installation

```bash
git clone https://github.com/elegharbi/wifakbank-rh-system.git
cd wifakbank-rh-system
```

### Base de données

```sql
CREATE DATABASE wifak_bank_rh;
```

### Dépendances frontend

```bash
cd frontend
npm install --legacy-peer-deps
```

> Le drapeau `--legacy-peer-deps` est nécessaire : `@angular/animations`
> exige une version exacte de `@angular/core` que npm refuse de résoudre seul.

## Configuration

Le fichier `application.properties` **n'est pas versionné** : il contient des
identifiants. Créez-le à partir du modèle fourni.

```bash
cp src/main/resources/application.properties.example \
   src/main/resources/application.properties
```

Puis renseignez les valeurs :

| Clé | Description |
|---|---|
| `spring.datasource.url` | URL JDBC (port `5433` par défaut dans le modèle) |
| `spring.datasource.username` | Utilisateur PostgreSQL |
| `spring.datasource.password` | Mot de passe PostgreSQL |
| `huggingface.api.token` | Jeton Hugging Face pour l'assistant RH |
| `spring.mail.username` / `spring.mail.password` | Compte SMTP des notifications |

L'application démarre sans jeton Hugging Face ni SMTP — seules les
fonctions correspondantes sont alors indisponibles.

### Attention : `ddl-auto`

Le modèle est livré avec :

```properties
spring.jpa.hibernate.ddl-auto=create
```

**Le schéma est supprimé et recréé à chaque démarrage.** Pratique pour une
première installation, destructeur ensuite. Passez à `update` dès que vous
saisissez des données à conserver.

## Lancement

Deux terminaux :

```bash
# Terminal 1 — API (port 8081)
mvn spring-boot:run
```

```bash
# Terminal 2 — interface (port 4200)
cd frontend
npm start
```

Ouvrez **http://localhost:4200**.

Le serveur de développement Angular relaie `/api` vers `localhost:8081`
(voir `frontend/proxy.conf.json`) — aucune configuration CORS n'est requise.

### Artefact unique

Pour obtenir un JAR contenant **aussi** l'interface :

```bash
cd frontend && npx ng build --configuration production && cd ..
mvn -DskipTests package
java -jar target/rh_system-0.0.1-SNAPSHOT.jar
```

Tout est alors servi sur un seul port. C'est ce que déploie
[DEPLOYMENT.md](DEPLOYMENT.md).

## Architecture

```
wifakbank-rh-system/
├── src/main/java/com/wifakbank/rh_system/
│   ├── controller/        # Points d'entrée REST
│   ├── service/           # Logique métier
│   ├── repository/        # Accès données (Spring Data JPA)
│   ├── config/            # Sécurité, JWT, CORS
│   ├── model/             # Entités partagées
│   └── *.java             # 15 entités JPA
│
├── src/main/resources/
│   ├── application.properties.example
│   └── data.sql           # Départements et postes initiaux
│
└── frontend/src/
    ├── app/
    │   ├── components/
    │   │   ├── core/      # Accueil, connexion, inscription, profil
    │   │   ├── employee/  # Espace collaborateur
    │   │   ├── admin/     # Espace administrateur
    │   │   ├── hr/        # Espace RH
    │   │   └── shared/    # Layout, assistant, dialogue de confirmation
    │   ├── services/      # Clients HTTP et état applicatif
    │   └── guards/        # Contrôle d'accès par rôle
    ├── styles.css         # Feuille de base
    └── theme-wifak.css    # Design system (couleurs, relief, thème sombre)
```

**Sécurité** — authentification JWT, jeton en cookie `HttpOnly`, mots de
passe hachés en BCrypt, routes protégées par rôle côté serveur et côté client.

## Dépannage

| Symptôme | Cause | Solution |
|---|---|---|
| `password authentication failed` | Identifiants erronés dans `application.properties` | Vérifiez le fichier ; il n'est pas versionné |
| `relation "..." does not exist` | Schéma absent | Laissez `ddl-auto=create` au premier lancement |
| `GENERATED BY DEFAULT AS IDENTITY` refusé | PostgreSQL antérieur à la version 10 | Installez PostgreSQL 10 ou supérieur |
| `Port 8081 was already in use` | Instance précédente encore active | Arrêtez le processus Java résiduel |
| `ERESOLVE` à l'installation npm | Conflit de dépendances Angular | `npm install --legacy-peer-deps` |
| Accents affichés `Ã©` | Encodage du script SQL | Vérifiez `spring.sql.init.encoding=UTF-8` |
| Modifications CSS invisibles | Cache du navigateur | Rechargement forcé (`Ctrl+Shift+R`) |
